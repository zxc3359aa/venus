# 平台接口生产化前置清单

生成日期：2026-06-15

本文用于把“写任何平台接口之前，先用 Context7 查最新官方文档”落成可执行检查项。当前仓库只允许离线 Fake/Mock、接口草稿和 `Action` 审批草稿；真实平台调用必须等 Context7 工具可见并完成文档核验后再写。

## 1. Context7 启用状态

项目配置已声明：

```toml
[mcp_servers.context7]
command = "npx"
args = ["-y", "@upstash/context7-mcp"]
```

依据：

- Context7 官方仓库/文档仍支持 MCP server 方式；本项目使用 npm 包 `@upstash/context7-mcp` 的本地 `npx` 启动方式。参考：[upstash/context7](https://github.com/upstash/context7)。
- Context7 官方说明也列出远程 MCP URL 与 API key 方式；API key 只应放在本机环境变量或用户级配置中，不能提交到仓库。

注意：

- 当前会话已经启动，新增 MCP 配置通常需要重启或重载 Codex 会话后才会出现在工具列表。
- 在工具列表可见并能查询文档前，不能实现真实飞书、抖音、巨量引擎、企业微信或微信小程序接口。

## 2. 每个平台接口开工前必须留下的证据

每写一个真实平台接口前，在 PR 描述或阶段文档中记录：

- Context7 查询的库/平台名称。
- Context7 返回的官方文档主题或库 ID。
- 被核验的接口、scope、权限、资质、频控、回调、安全要求。
- 代码中的 `// VERIFY-DOC:` 项是否已消解。
- 输入/输出 `Tagged` 数据级别与目的地流向。
- 是否会产生对外不可逆动作；如是，必须只构造 `Action` 并走 `ApprovalGate`。

## 3. 平台级红线

飞书：

- 必须使用维纳斯独立自建应用，不复用“小龙虾”的 App ID、Secret、事件订阅、进程、数据目录或文件空间。
- 长连接、事件订阅、卡片交互、回调验签、事件去重、重连策略需经 Context7/官方文档核验。
- 审批按钮只改变审批状态，不直接执行不可逆动作。

抖音开放平台：

- 只处理本账号授权数据与官方允许的评论/内容能力。
- 不写直接爬取抖音、模拟登录、绕验证码、批量抓竞品页面或非官方弹幕自动发送。
- 发布视频、公开回评等不可逆动作必须先审批。

巨量引擎/千川/星图：

- 必须核验广告主授权、企业资质、scope、预算/投放接口、频控和回调口径。
- 创建/修改/开启投放、花费预算、接单等动作必须先审批。
- 投放策略仍受 M7 的预算上限、学习期保护、止损、ROAS/CPA 护栏约束。

企业微信/微信小程序：

- 必须核验主体认证、scope、用户授权、隐私告知、数据留存和回调要求。
- 加客户、发消息、收集私域个人信息必须显式同意、C3 标记、脱敏存储，并走审批。

## 4. 当前允许推进的工作

- 完善离线 Fake/Mock 与契约测试。
- 编写接口设计文档、数据流向图、审批流程图和字段占位。
- 在代码中保留 `official_api_status=pending_context7_verification` 或 `// VERIFY-DOC:`。
- 准备账号资质、scope 清单和本地环境变量说明。

## 5. 当前禁止推进的工作

- 在 Context7 不可用或未完成文档核验时写真实平台 HTTP/SDK 调用。
- 将 C3 画像、原始语料、私域个人信息发送给云端模型、第三方数据源或云训练服务。
- 绕过官方/授权来源采集抖音或竞品数据。
- 自动执行发视频、回评论、投流花钱、加客户、删数据等不可逆动作。
